PORTION TRACK — Steps feature
QA Test Guide (simple, step-by-step)
For testers who may not be technical
Last updated: 8 October 2026

================================================================================
WHAT THIS FEATURE DOES (plain English)
================================================================================

Portion Track can show how many steps the user walked today.

- The user turns this on in Settings.
- The phone’s health app shares today’s step number with Portion Track.
- Portion Track shows that number and a simple progress bar toward a daily goal.
- The step number stays on the phone. We do not upload it to our servers.
- This is optional. If the user never turns it on, nothing changes.

Important:
- This will NOT work in Expo Go.
- You need a real phone install (Android test APK or iPhone TestFlight).
- On the Android test APK, real subscription purchase will NOT work.
  Use the special unlock below.

TEST 3 — Connect Steps (first time)
================================================================================

Goal: User can connect and allow permission.

Steps
1. In Settings → Steps, confirm it says Not connected.
2. Turn the switch ON.
3. The phone should show a permission screen:
   - Android: Health Connect asking to allow Steps
   - iPhone: Apple Health asking to allow Steps
4. Allow / turn on Steps.
5. Return to Portion Track.
6. Confirm Settings → Steps now says Connected.
7. Confirm a “Today’s steps” number is shown
   (0 is okay if you have not walked yet).

Pass if
- Permission screen appears
- After allowing, status is Connected
- Today’s number is shown (including 0)

Fail if
- Switch does nothing
- App crashes
- Permission screen never appears
- Status stays Not connected after you allowed access

TEST 4 — Make sure the phone is actually counting steps
================================================================================

Goal: Confirm the phone health app has step numbers.
If the phone has 0 steps, Portion Track will also show 0. That is not an app bug.

Android steps
1. Open the Health Connect app.
2. Go to Data and access (or Data).
3. Tap Steps.
4. Check that some app is allowed to write/add steps
   (usually Google Fit or Samsung Health).
5. Check that Portion Track is allowed to read steps.
6. Open Google Fit (or Samsung Health), open it once, allow activity if asked.
7. Put the phone in your pocket and walk for 2–3 minutes.
8. Open Health Connect again and check whether today’s steps went up.

iPhone steps
1. Open the Apple Health app.
2. Find Steps (Browse → Activity → Steps is fine).
3. Check today’s number.
4. If it is 0, walk for 2–3 minutes with the iPhone.
5. Confirm today’s steps went up in Apple Health.

Pass if
- Health Connect / Apple Health shows steps for today, or the number increases after walking

Fail if
- No app is writing steps on Android and you cannot get any step data
  (tell the developer; Portion Track cannot invent steps)

TEST 12 — Permission removed after connecting
================================================================================

Goal: If the user later turns off permission, the app handles it calmly.

Android
